# 🧠 CNN Concepts Covered

## 1. Convolution

A convolutional filter moves over an image to produce a feature map.
Early filters can respond to local patterns such as edges and textures;
deeper layers can learn more complex patterns during training.

## 2. Padding and Stride

-   **Padding** adds pixels around an image or feature map and can help
    control the spatial output dimensions.
-   **Stride** controls how far a filter moves at each step.
-   Changing padding and stride changes the output feature-map size.

For a 2D convolution, a common output-size formula for one spatial
dimension is:

\[ O = `\left`{=tex}`\lfloor `{=tex}`\frac{N + 2P - K}{S}`{=tex}
`\right`{=tex}`\rfloor `{=tex}+ 1 \]

where (N) is the input size, (P) is the padding size, (K) is the kernel
size, and (S) is the stride.

## 3. Pooling

-   **Max pooling** returns the maximum value in each local window.
-   **Average pooling** returns the mean value in each local window.
-   Pooling reduces spatial dimensions and can reduce the amount of
    computation passed to later layers.

## 4. Flattening and Dense Layers

Flattening converts a multi-dimensional feature map into a
one-dimensional vector so it can be passed to dense layers. The final
classification layer produces scores for the 10 CIFAR-10 classes.

## 5. Backpropagation and Training

During training, the model calculates a loss from its predictions and
the target labels. Backpropagation computes gradients, and an optimiser
uses those gradients to update trainable parameters. Training and
validation curves help reveal learning progress and possible
overfitting.

## A5 --- Data Augmentation

Data augmentation applies label-preserving transformations to training
images to expose the model to more varied examples.

Depending on the notebook configuration, transformations may include
image flipping, rotation, translation, zoom or other supported image
transformations.

This section visualises augmented examples and supports a comparison
between models trained with and without augmentation, where the
corresponding experiments are executed.

**Expected outputs:** augmented-image examples and any
training/evaluation comparison produced by the notebook.

## A6 --- Transfer Learning: Feature Extraction and Fine-Tuning

This section uses **MobileNetV2** as a pretrained feature extractor and
explores fine-tuning.

-   **Feature extraction:** use the pretrained convolutional base while
    keeping its weights frozen, then train a task-specific
    classification head.
-   **Fine-tuning:** unfreeze selected pretrained layers and continue
    training carefully with a suitably small learning rate.

The notebook may download pretrained MobileNetV2 weights on first use.
Internet access may be required for that download. Image resizing and
model-specific preprocessing must be consistent with the
transfer-learning model.

**Expected outputs:** transfer-learning training curves, evaluation
metrics, and a comparison with the CNN models if all experiments

# ⚠️ Troubleshooting

### TensorFlow installation fails

Check your Python version and TensorFlow compatibility. Install the
dependencies in a virtual environment if your system has conflicting
packages.

### CIFAR-10 download fails

Check your internet connection and rerun the dataset-loading cell. Once
downloaded successfully, Keras usually caches the dataset locally.

### MobileNetV2 weights cannot be downloaded

Check internet access and rerun the transfer-learning setup cell. The
transfer-learning section may not run until the pretrained weights are
available.

### Notebook runs out of memory or is too slow

Reduce the batch size or number of epochs for a test run, and avoid
keeping multiple large models in memory at once. Record any
configuration changes in your report.

### Result plots are missing

Run the model-training and evaluation cells first. The demonstration
images included in `plots/demonstrations/` do not represent measured
model performance.

### Notebook package imports fail

Install the requirements in the same Python environment used by the
Jupyter kernel, then restart the kernel and rerun the notebook.
